# Cintas y medallas

Este archivo debe consultarse antes de crear, editar o guardar cintas y medallas.

## Objetivo

Las insignias del perfil pueden ser cintas, medallas o ambas juntas. Cada insignia debe poder asociarse a un premio completado y mostrarse en el orden correcto dentro de la interfaz.

## Orden

- Cada cinta y cada medalla debe tener un numero de orden.
- El orden define como se presentan visualmente cuando un usuario tiene varias insignias.
- El numero de orden debe quedar documentado junto al nombre del archivo o en el catalogo que consuma la aplicacion.

## Cintas

- Deben parecer cintas reales de hilo.
- Deben ser pequenas, ligeras y aptas para carga rapida.
- Deben guardarse como WebP solo despues de aprobar el ejemplo visual.
- No deben tener margen externo, fondo sobrante ni espacio transparente innecesario.
- El recorte debe quedar exactamente al borde visible de la pieza.
- Cuando haya varias cintas de una misma serie, deben mantener una misma proporcion, nitidez, textura, luz y tonalidad.

## Medallas

- Deben parecer piezas reales, con hilo y metal segun corresponda.
- Todas las medallas de una misma serie deben tener el mismo tamano, calidad, entonacion y luminosidad.
- Deben guardarse como WebP optimizado solo despues de aprobar el ejemplo visual.
- No deben tener margen externo, fondo sobrante ni espacio transparente innecesario.

## Peso y formato

- El peso debe ser lo mas bajo posible sin perder legibilidad ni textura.
- Preferir WebP para assets finales.
- Evitar imagenes grandes si se usaran pequenas dentro de la aplicacion.

## Flujo de trabajo

1. Crear o preparar primero una vista de ejemplo.
2. Presentar la imagen aqui para revision.
3. Guardar como WebP en la carpeta correspondiente solo cuando se apruebe.
4. Registrar o usar el numero de orden correspondiente.
